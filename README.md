# Fête « Tour du monde » — espace des organisateurs

Page de suivi de la fête de l'assemblée du 20 décembre 2026 : réponses des
foyers, offrandes, buffet, matériel, déroulé et animations, dates et décisions.

**Ce dépôt ne contient aucune donnée.** Pas de noms, pas de montants, pas de
coordonnées. Tout vit dans une base Supabase, derrière une connexion par lien
envoyé par mail, et n'est chargé qu'une fois la personne reconnue comme membre
de l'équipe. Les fichiers publiés ici ne sont qu'une coquille.

| | |
|---|---|
| `index.html` | la page : onglets, styles, rendu |
| `acces.js` | la connexion par mail et la base partagée en direct |
| `config.js` | l'adresse du projet Supabase et sa clé publique |

La clé de `config.js` est faite pour être publique : ce sont les règles d'accès
de la base (RLS) qui gardent la porte.
